# Server Owner Profile

- Technical level: Non-Linux, non-coding user (default). Prefer plain-English summaries, clear status outcomes, and step-by-step confirmation before server changes.
- Approval preference: Explain risk clearly and wait for explicit approval before installing, modifying, or removing workloads.
- Communication style: Concise, calm, and reassuring. Highlight only actionable next steps; avoid dumping raw terminal logs unless asked.
